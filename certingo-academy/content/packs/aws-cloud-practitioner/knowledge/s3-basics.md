# AWS S3 - Simple Storage Service

Amazon S3 is an object storage service that offers industry-leading scalability, data availability, security, and performance.

## Key Concepts
- **Buckets**: Containers for objects. Must have a globally unique name.
- **Objects**: The fundamental entities stored in S3 (files + metadata).
- **Keys**: The unique identifier for an object within a bucket.

## Durability and Availability
- Durability: 99.999999999% (11 nines).
- Availability: Designed for 99.99% availability.
